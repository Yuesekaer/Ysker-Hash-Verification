## 一、软件概况

| 项目 | 内容 |
|---|---|
| 名称 / 版本 | **Ysker-文件校验　v1.0.1** |
| 形态 | 单个自包含 .exe（无需安装、无需联网、不写任何配置文件，纯便携） |
| 技术 | C# WinForms，只使用 .NET **4.0** API（可在装有 .NET 4.x 的 Win7 SP1 及以上运行） |
| WinPE | 需要映像里带 .NET（例如 `WinPE-NetFx` 包） |
| 图标 | `assets\MD5.ico` |
| 制作署名 | 侧栏「小技巧」下方固定一行：`本工具制作：Yuesekaer`（与小技巧同色同字号） |
| 校验算法 | **MD5 / SHA1 / CRC32 / SHA-256** |
| 默认状态 | 只勾 **MD5**；显示**大写**；显示文件大小与卡片「复制」按钮；「同文件分类」**关**；「框选」**关**；「置于顶层」**关** |
| 窗口 | 初始 `1240×740`，最小 `1000×580`；无系统边框，标题栏自绘；四边四角可拖拽缩放 |
| 配色 | 底色 `#1F1F1F`、卡片 `#2A2A2A`、主按钮 `#1EA12D`（悬停/按下 `#15CE2A`）、`×` `#C83C26`（悬停 `#E54529`）、闪烁绿 `#2EAF3D`、框选选中 `#46C032` |

## 三、功能清单与使用方法

### 1) 添加文件
- **选择文件**：可按住 `Ctrl` / `Shift` 多选。
- **选择文件夹**：**连同子文件夹**一起加入。
- **拖放**：把文件或文件夹直接拖进窗口即可（支持多选拖放）。
- 重复添加同一个路径不会产生重复卡片。

### 2) 选择校验算法（右栏「校验值选择」）
- 四个开关可**自由组合**：`MD5` / `SHA1` / `CRC32` / `SHA-256`。
- **默认只勾 MD5**。
- 取消某个勾选 → 卡片里对应的那一行**立刻消失**（不用重新校验）。
- 重新勾上 → 自动**补算**该算法，并**只让新勾的这一行渐亮**（已显示过的不会重亮）。
- **四个都不勾** → 状态栏提示 `至少得选一个吧(｀・ω・´)`，校验不执行。

### 3) 开始校验
- 按钮 `开 始 校 验` 或按 `F5`。
- 校验中：卡片上方出现进度条；状态栏显示 `正在校验中...  N% (如文件较大可能会暂时卡几秒，请耐心等待)`；卡片顶部进度条显示 `正在校验中...  N% (如文件较大可能会暂时卡几秒，请耐心等待)   (已完成/总数)  文件名`（空间不够时**只截文件名**，进度与提示始终完整）。
- 完成：状态栏 `校验完成：N 个文件（全部正常）` 或 `（N 个读取失败）    显示项：MD5 / …`。
- 单个文件读取失败：该卡片显示 `读取失败：<原因>`，不影响其他文件。

### 4) 哈希值 = **只读文本层**（像记事本一样选中复制）
哈希值那几行是真正的系统只读文本控件，行为与记事本一致：
- **左键按住拖动**即可连续划选，**松开后保持高亮**；
- 支持**从右往左**拖、**双击选词**、**Shift+点击扩展**、`Ctrl+A`；
- `Ctrl+C` 或 **右键 → 复制** 复制所选片段；
- 焦点移开、点击软件其他空白处（侧栏/状态栏/列表空白）→ 选区消失；
- **不可编辑**：输入、粘贴、删除、剪切全部无效；
- **不出现可输入光标**（无闪烁竖线），**不弹软键盘**（不激活输入法）；
- 在哈希值上滚轮 → 滚动的是**文件列表**（不是文本框）。

### 5) 卡片操作
- **`×`**：把该文件从列表移出。
- **`复制`**：只复制**这一个**文件当前显示的校验值。
- 文件大小显示在卡片右下角（`B / KB / MB / GB`，1 位小数）。

### 6) 框选模式（右栏「框选（点一下即多选）」，**默认关**）
- 开启后：**点一下卡片即选中**（不用按 Ctrl），再点一下取消；可**按住左键在空白处拖出选择框**批量选中。
- `Ctrl+A` 全选；`Delete` / `Backspace` 批量移除选中项。
- 开启框选时，哈希值的"文本划选"层自动让位（点击用于选卡片），关闭后恢复。
- 状态栏右侧会显示 `选中 N` 与 `框选：开/关`，标题也会提示选中数量。

### 7) 大小写切换（右栏「显示 → 大小写：大写/小写」）
- 作用于**卡片显示、复制、比对、导出**里的全部十六进制值；CRC32 同样跟随。
- 默认**大写**。

### 8) 同文件分类（右栏「显示 → 同文件分类（一致时分组）」，**默认关**）
- **开启**：校验完成后，把所有**内容一致**的文件排到最前面并按组分块，每组末尾插一条分隔线：
  `———  以上 N 个文件完全一致（MD5+SHA1+CRC32+SHA-256）  ———`，并自动滚到第一组。
- **关闭（默认）**：列表保持原顺序、**不分组**，但**仍然会把内容一致的哈希行依次渐亮**，状态栏提示 `发现 N 组内容一致（「同文件分类」关闭，未分组显示）`。
- 随时切换：打开立即分组，关闭立即恢复平铺列表。

### 9) 渐亮闪烁规则
- 参与对象：**内容互相一致**的那几组文件（按当前勾选算法组合判断）。
- 顺序：`MD5 → SHA1 → CRC32 → SHA-256`，**同一算法所有相关行一起亮、一起灭**；
- 单行节奏：0.1s 渐亮 → 0.6s 保持 → 0.3s 渐回白色（绿色 `#2EAF3D`）；
- **只有"新勾上/新补算"的算法才会闪**，已经闪过的不会重亮；
- **「比对」命中的那一行单独闪**（不整组逐行闪）；
- 闪烁**不会**改变你的划选、也不会把整段选中。

### 10) 待对比值（右栏「待对比值」+ `比  对`）
- 输入/粘贴一个哈希值（或按 `Enter`）→ 点 `比  对`。
- **自动识别算法**：长度 8→CRC32、32→MD5、40→SHA1、64→SHA-256。
- **尚未校验时会自动先校验**，完成后再比对（不会误报"没有匹配"）。
- **命中**：滚动到那一行并让该行渐亮；状态栏提示命中信息。
- **未命中**：状态栏 `很遗憾，没有匹配的值(；´д｀)ゞ`；若是该算法当前没勾选/没算，会附注 `（提示：当前没有勾选/计算 XXX）`。
- 比对**不会**改动列表的选中项，也**不会**分组。

### 11) 复制 / 导出
- **复制选中哈希值**：有选中文件时只复制选中的；**没有任何选中时复制列表里全部文件**的哈希值。
- **复制全部哈希值**：不管勾选与选中，复制列表中所有文件的**四个算法全部值**。
- **导出结果为 txt**（`Ctrl+S`）：UTF-8 带 BOM，格式：
  ```
  Ysker-文件校验  导出时间：2026-10-12 20:39:59
  文件数量：12    校验值：MD5 / SHA1 / CRC32 / SHA-256    大写
  ------------------------------------------------------------
  <完整路径>
    MD5：....
    SHA1：....
    CRC32：....
    SHA-256：....
  ```

### 12) 窗口
- **置于顶层**（标题栏最左侧图钉 📌，默认关）：窗口始终在最前；开启时按钮底色常亮，再点关闭。
- **最小化 / 最大化（还原）/ 关闭**：标题栏右侧；悬停最小化与最大化为绿底，关闭为红底。
- **缩放**：拖四边／四角；最小 `1000×580`；双击标题栏空白处 = 最大化/还原。
- **文字随窗口宽度自适应**：窗口变窄时卡片字号自动从 10.5pt 往下缩（每 0.25pt 一档，最低 7pt），
  保证 **SHA-256 的 64 个字符永远完整显示**；路径行放不下时**先把这一行字号缩小**去放下整条，
  只有连最小字号都放不下才退化为"目录开头 + … + 完整文件名"。

### 13) 右键菜单（窗口任意处或列表上右键）
`选择文件…(Ctrl+O)` ｜ `选择文件夹…` ｜ `开始校验(F5)` ｜ `查找一致文件(Ctrl+F)` ｜
`比对输入框里的值(Ctrl+K)` ｜ `复制选中哈希值(Ctrl+C)` ｜ `复制全部哈希值` ｜
`导出结果为 txt…(Ctrl+S)` ｜ `全选(Ctrl+A)` ｜ `删除选中文件(Delete)` ｜ `清空列表(Ctrl+Delete)` ｜
`打开图标文件位置`

### 14) 状态栏
- 左侧：操作提示 / 校验进度 / 结果 / 错误（如未勾选算法、未命中）。
- 右侧摘要：`N 文件 ｜ 已校验 N ｜ 选中 N ｜ MD5+SHA1… ｜ 大写/小写 ｜ 框选：开/关`。
- 状态栏横跨到窗口最右边。

## 四、快捷键总表

| 快捷键 | 作用 |
|---|---|
| `F5` | 开始（重新）校验 |
| `Ctrl+O` | 选择文件 |

| `Ctrl+Delete` | 清空列表 |
| 拖放 | 文件/文件夹拖进窗口 |

## 五、全盘测试清单（按编号测，逐条对"期望"）

### A. 启动与外观
1. 双击 exe → 标题栏显示 `Ysker-文件校验  v1.0.1`；窗口约 1240×740 居中；状态栏显示 `准备好了，把文件拖进来吧～`。
1b. exe 的图标是 **MD5.ico**（文档+放大镜样式），不是旧图标。
1c. 侧栏「小技巧」最后一行下方有 ` 本工具制作：Yuesekaer `，**颜色与字号和小技巧完全相同**，且没有被裁掉。
2. 标题栏右侧**四个**按钮：图钉、─、□、✕；悬停 ─/□ 变绿底、✕ 变红底。
3. 图钉：点击一次 → 窗口置顶且图钉底色常亮；再点 → 取消。
4. 拖窗口四边/四角 → 能缩放，且**对边固定**（拖动时不会整体平移）；缩不到比 1000×580 更小。
5. 双击标题栏空白 → 最大化/还原（还原按钮图标同步变化）。
6. 关闭 → 进程退出（任务管理器里无残留）。

### B. 添加文件
7. `选择文件` → 可 Ctrl/Shift 多选 → 卡片按加入顺序出现，路径完整显示。
8. `选择文件夹` → **递归**加入子文件夹里的文件。
9. 把若干文件和**一个文件夹**一起拖进窗口 → 全部加入。
10. 重复拖入同一路径 → 不产生重复卡片。

### C. 算法勾选
11. 启动时只有 **MD5** 是勾选态（绿底 √），其余三个是未勾选（深底）。
12. 校验后取消 `SHA-256` → 卡片里 SHA-256 那一行**立刻消失**，其他行不动。
13. 再勾上 `SHA-256` → 自动补算，且**只有 SHA-256 这一行**渐亮一次（MD5 等不重亮）。
14. 把四个全部取消 → 状态栏 `至少得选一个吧(｀・ω・´)`；按 F5 不执行校验。
15. 四个全勾 → 每张卡片显示 4 行，`：` 全部对齐成一列。

### D. 校验
16. 点 `开 始 校 验` → 出现进度条，状态栏显示 `正在校验中...  N% (如文件较大可能会暂时卡几秒，请耐心等待)`（**整句完整显示、不被省略号截断**）；校验中按钮不可重复触发。
17. 完成后状态栏 `校验完成：N 个文件（全部正常）` 并列出 `显示项：…`。
18. 放一个**无权限/被占用**的文件 → 该卡片显示 `读取失败：…`，其余正常，状态栏括注读取失败数量。
19. 校验后再按 F5 → 重新校验（数值一致）。

### E. 哈希值文本划选（重点）
20. 在 MD5 值上**从左往右**拖 → 连续高亮、松开保持。
21. **从右往左**拖 → 同样高亮，且范围正确。
22. **双击**某个值 → 选中整段（双击选词）。
23. 按住 `Shift` 再点击 → 从上次位置扩展到点击处。
24. 选中后 `Ctrl+C` → 粘贴出来**恰好是框住的那段**（不多不少）。
25. 选中后**右键 → 复制** → 同上。
26. 点击侧栏/状态栏/列表空白 → 选区消失。
27. 试着输入字母、按 `Delete`、按 `Ctrl+V` → **毫无反应**，内容不变。
28. 观察是否有**闪烁的输入光标** → 不应出现。
29. 鼠标停在某行哈希值上滚轮 → **文件列表滚动**（不是文本框内部滚动）。
30. 拖选时看是否有**异常扩大的选中框**、是否自动选中整段 → 不应出现。
31. 拖选后 `Ctrl+C` → 剪贴板**不是**整份列表，只是你框住的内容。

### F. 渐亮闪烁（重点）
32. 放入两个**内容相同**的文件 + 一个不同文件（CRC32/SHA-256 都勾上）→ 校验：
    MD5 先两行一起亮→灭，然后 SHA1、CRC32、SHA-256 依次；**同一算法同亮同灭**。
33. 只有内容一致的文件会闪，其他文件不闪。
34. 闪烁是**渐亮渐灭**（不是硬切），单行约 1 秒。
35. 闪烁期间拖动划选 → 选区不被搅乱、没有闪烁的选中框。
36. 闪烁结束后，所有哈希值**全部回到白色**（不会整块留绿、不会卡在某一行绿）。

### G. 同文件分类（默认关）
37. 默认状态：校验后列表**顺序不变、没有分隔线**（但一致项仍会闪烁一次）。
38. 打开「同文件分类」→ 一致的组排到前面并出现 `———  以上 N 个文件完全一致（…）  ———`，并自动滚到第一组。
39. 再关闭 → 立即恢复平铺列表（顺序回到原样）。
40. 关闭状态下点 `查找一致文件`(Ctrl+F) → 不分组，但会闪烁一致项并提示"未分组显示"。

### H. 大小写
41. 默认大写。点 `大小写：大写` → 按钮文字变 `大小写：小写`，所有值（含 CRC32）变**小写**。
42. 小写状态下复制/比对/导出 → 都是小写；再切回大写同理。

### I. 比对
43. 复制某个文件的 MD5，粘进「待对比值」→ `比  对` → 列表滚到该行并**只让这一行**渐亮。
44. 输入一个**不存在**的值（32 位）→ 状态栏 `很遗憾，没有匹配的值(；´д｀)ゞ`。
45. **未校验时**直接比对 → 自动先校验再比对（不会立刻报"没有匹配"）。
46. 输入 8/40/64 位值 → 分别按 CRC32/SHA1/SHA-256 比对；若该算法没勾选 → 提示里附注 `（提示：当前没有勾选/计算 XXX）`。
47. 比对过程与结果**不改变**列表的选中状态、**不产生分组**。

### J. 复制与导出
48. 直接点 `复制选中哈希值`（没有任何选中）→ 复制全部文件的哈希值。
49. 框选两个文件后再点 → 只复制这两个。
50. `复制全部哈希值` → 不管勾选/选中，四个算法全给。
51. 每张卡片的 `复制` → 只复制这一个文件（状态栏 `已复制：<文件名> 的校验结果`）。
52. `导出结果为 txt` → 选路径保存；打开确认表头三行 + 分隔线 + 每个文件的路径与全部值；中文不乱码（UTF-8 BOM）。

### K. 框选
53. 开启「框选」→ 点一下卡片即选中（卡片有选中标识）；再点一下取消。
54. 在空白处按住左键拖出选择框 → 框到的卡片被选中。
55. `Ctrl+A` 全选；`Delete` 删除选中项（卡片消失）。
56. 开启框选时在哈希值上拖动 → 不会划选文字（此时点击用于选卡片）；关闭框选后恢复文本划选。
57. 状态栏右侧 `选中 N`／`框选：开` 同步变化。

### L. 卡片与列表
58. 点卡片 `×` → 该卡片移出，其余不动。
59. 清空列表 → 全部移除；状态栏恢复提示。
60. 列表滚动：**鼠标停在卡片上**滚轮可滚动；停在卡片之间的缝隙也能滚动；右侧滚动条可拖。
61. 侧栏（右栏）滚动条是**深色自绘**的（不是系统白色条），可拖、可用滚轮。

### M. 缩放与长文本
